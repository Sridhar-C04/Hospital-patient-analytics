# Hospital Patient Analytics

## Project Overview

Hospital Patient Analytics is a healthcare business intelligence project developed to analyze patient demographics, treatment outcomes, survival trends, and clinical performance indicators. The dashboard transforms healthcare data into actionable insights that support informed decision-making and operational efficiency.

---

## Objectives

- Analyze patient demographics and clinical characteristics
- Evaluate treatment outcomes and survival rates
- Monitor healthcare KPIs and performance metrics
- Identify trends across patient groups
- Support data-driven healthcare decision making

---

## Tools & Technologies

- Power BI
- DAX
- Power Query
- Excel
- Data Modeling
- Data Visualization

---

## Key Performance Indicators

- Total Patients
- Survival Rate
- Mortality Rate
- Gender Distribution
- Age Group Analysis
- Tumor Stage Distribution

---

## Dashboard Features

- Interactive KPI Cards
- Survival Rate Analysis
- Patient Demographic Insights
- Treatment Outcome Evaluation
- Dynamic Filtering & Slicers
- Executive-Level Healthcare Reporting

---

## Business Insights

This project enables healthcare stakeholders to monitor patient outcomes, evaluate treatment effectiveness, identify demographic patterns, and improve strategic decision-making through data-driven insights.
